Cooking Rush: run a 120-second kitchen shift — pick orders from the board, tap their 3 ingredients to fill the plate, and serve before patience runs out. Fast serves build a combo and earn more coins. 15 ingredients, 7 dishes, up to 3 orders at once, fully offline in the browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Or open game/index.html directly.

Hand in the entry with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
